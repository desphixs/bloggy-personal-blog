# Build Bloggy: A Clean Personal Blog

### Project Description

You are going to build Bloggy a beautiful and fully functional blog where you can publish articles and let visitors leave comments. First you will set up a database table for your blog posts. Next you will learn the most important concept in database design: relationships. You will create a comment table and link it directly to your posts. Then you will write Python functions to show a list of all your posts and create special dynamic pages where visitors can read the full article. Finally you will add a form right at the bottom of the article so visitors can instantly share their thoughts. You will write all of this using clear function based views so you truly understand how the pieces fit together.
